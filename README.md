# Clean and Compact

Organize an assistant’s context, memory and files while preserving important material.

## Install

Clone this repository into your agent's skills directory, keeping `SKILL.md` and its supporting files together. For Codex:

```sh
git clone https://github.com/felipepetersmann22-star/clean-and-compact-skill.git ~/.codex/skills/clean-and-compact
```

Restart or refresh skill discovery if needed. Other agents may use a different skills directory.

## Use

Use when reviewing an idle assistant’s accumulated context, memory or files. The skill references companion skills from the original pack, including `lean-chats`, `frugal-routines`, `reuse-before-research` and `weekly-cleanup-review`. They are separate repositories; install any that your workflow needs.
